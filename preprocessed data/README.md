# Local Processed Data

This local folder contains the processed inputs used by the thesis analyses:

- `diagnosis_ADNI2/`: paired MRI and AV45-PET regional features, feature dictionary, and GNN-selected regions.
- `prognosis_ADNI_longitudinal_MCI/`: longitudinal MCI prognosis features, MMSE scores, event/censoring fields, and model feature list.

These tables are participant-level ADNI-derived data. They are retained locally to support reproducibility but excluded from Git and the source-only upload ZIP. Do not redistribute them without checking the applicable ADNI data-use terms.
